### ブラウザ操作

Playwrightは入力欄への実ファイル選択とブラウザが生成したダウンロードファイルを検証します。サンプルの表示内容を固定値で置き換えたテストではありません。PDFのCanvasに実際の文字・罫線の画素があることも確認します。

1. 日本語請求PDFを入力 → 原本と表表示 → セル編集 → 見出し指定 → 行削除・Undo → 列削除・Undo → 確認チェック → CSVダウンロード・バイト列検証。
2. 2ページ売上PDF → 2表検出 → 表選択とPDFページ同期 → ページ移動。
3. 同ページ2表の商品PDF → 空欄の警告 → 表切替 → XLSX全表出力 → 2シートの実ファイル読戻し。
4. 空白PDF、文章PDF、不正ファイル → 適切な案内・エラー。
5. モバイル → 初期画面・表表示 → PDF切替 → 編集 → 本文の水平はみ出しなし。
